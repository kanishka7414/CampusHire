\# CampusHire – Placement Management System



CampusHire is a full-stack web application designed to simplify the campus placement process for students and administrators.



\## 🚀 Features



\### 👩‍🎓 Student



\* Student registration and login

\* Create and manage student profile

\* Add and manage skills

\* View available companies

\* Check company eligibility

\* Apply for job opportunities

\* Track application status



\### 👨‍💼 Admin



\* Admin login

\* View student applications

\* Update application status

\* Add new companies

\* Set minimum CGPA and required skills

\* Set application deadlines

\* View announced companies

\* Remove companies
